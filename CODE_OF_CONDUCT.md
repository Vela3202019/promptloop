# Code of Conduct

This project follows the Contributor Covenant, version 2.1.

The full text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be respectful, constructive, and inclusive. Harassment, discrimination, personal attacks, and publishing private information are not acceptable in project spaces.

Report conduct concerns to the repository maintainer through GitHub, either by direct message where available or through GitHub's private reporting/advisory mechanisms. Do not post private or sensitive details publicly.

Enforcement decisions are made by the project maintainer according to the Contributor Covenant guidelines.
